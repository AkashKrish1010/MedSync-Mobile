# MedSync-Mobile

MedSync Mobile is the cross-platform React Native (Expo) and Node.js clinical healthcare application.

## Overview
- **Mobile Client:** React Native + Expo + React Navigation + Lucide Icons
- **Backend:** Node.js + Express + WebSocket + MongoDB (with dynamic in-memory fallback)
- **Features:** Patient dashboard, doctor schedule & consultations, real-time clinical chat, electronic medical records, AI symptom & scan analyzer.
